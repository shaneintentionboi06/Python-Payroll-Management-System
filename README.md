# Employee Manager
This program allows Offices to manage Employee Database. It uses TUI, which makes it light and work on headless computers. 

## Getting Started

1. ### Clone This Repository
    Go to the Directory where you want to store this repository and run 
    ```git clone https://github.com/shaneintentionboi06/Employee-Management-System.git```

2. ### Install `uv` and sync packages
    install uv (Package Manager)
```pip install uv ``` <br>
    sync all packages
```uv sync```
3. ### Run the Program
``` uv run main.py ```
